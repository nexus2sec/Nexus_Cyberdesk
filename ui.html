    Phase 2 Research Block

    RBI Circular Simplified (DBR.No.Leg.BC.78/09.07.005/2017-18)

    If customer reports quickly

    Agar customer ne unauthorized transaction turant report kiya, liability zero ya very limited ho sakti hai.

    Delay increases liability

    Report delay hone par customer ki liability account type aur policy rules ke hisab se badh sakti hai.

    Bank must reverse in timeline

    Regulatory expectation hai ki valid complaints ka credit reversal defined turnaround time me ho.

    Always keep proof trail

    SMS, screenshots, complaint IDs, 1930 report, FIR/CSR details safe rakho. Ye recovery speed badhata hai.

    UPI Fraud SOP

    1. Bank app kholo and UPI disable ya block option tap karo.
    2. 1930 call karke transaction IDs bolo aur complaint ID note karo.
    3. Cybercrime portal complaint submit karo with screenshots.
    4. Branch visit karke written dispute form submit karo.

    WhatsApp Hijack SOP

    1. Turant contacts ko normal call karke alert kar do.
    2. WhatsApp me re-register with phone number and OTP.
    3. "Lost/Stolen" support email trigger karo with number format.
    4. 2-step verification PIN set karo and linked devices logout.

    Instagram Recovery SOP

    1. Login help page par "My account was hacked" select karo.
    2. Video selfie or identity verification prompt complete karo.
    3. Old recovery email/number ko restore request bhejo.
    4. Recovery ke baad password + 2FA app enable karo.
